# NotiFilter 1.0.1

NotiFilter 1.0.1 is a maintenance release containing internal code cleanup. There are no user-facing behavior changes.

## Changes

- Centralized the preferences notification name.
- Removed redundant main-queue hops in the root controller.

## Compatibility

Requires iOS 18.0 or later. Rootless and roothide packages are included.
